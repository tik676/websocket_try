# README

## О проекте

Это учебный пет-проект в микросервисной архитектуре: **анонимный чат с авторизацией**.  
Проект демонстрирует работу нескольких сервисов с обменом событиями через Kafka, использованием PostgreSQL для хранения данных и WebSocket для реального времени.  

### Основные возможности:
- Регистрация и логин пользователей (с JWT-аутентификацией).  
- Поддержка **анонимных пользователей** (авторизация без регистрации).  
- Чат с историей сообщений и поддержкой WebSocket.  
- Отправка событий в Kafka при регистрации / логине / действиях в чате.  
- Логирование событий в файлы отдельным сервисом.  
- Полностью контейнеризировано с Docker Compose.  

---

## 🏗 Архитектура

Проект состоит из 3 основных сервисов:

1. **User Service**  
   - REST API для регистрации / логина / логаута.  
   - Выдаёт JWT токены.  
   - При событиях (регистрация, логин) отправляет сообщения в Kafka.  
   - Использует PostgreSQL для хранения пользователей.  
   - Gin в качестве HTTP-фреймворка.  

2. **Chat Service**  
   - REST API для получения истории сообщений и удаления сообщений.  
   - Поддержка WebSocket для реального времени.  
   - Сообщения хранятся в PostgreSQL.  
   - Авторизация через JWT.  
   - Kafka для публикации событий (например, удаление сообщений).  

3. **Notification Service**  
   - Консьюмер Kafka.  
   - Слушает события (регистрация, логин, действия чата).  
   - Логирует их в файлы.  

### Инфраструктура:
- **PostgreSQL** — отдельная БД под каждый сервис.  
- **Kafka + Zookeeper** — брокеры сообщений.  
- **Docker Compose** — для локального запуска.  
- **Makefile** - для запуска через одну команду

## Запуск проекта

### Требования
- Docker + Docker Compose  

### Шаги запуска
```bash
# Клонировать репозиторий
git clone https://github.com/tik676/websocket_try.git
cd websocket_try

make build
```

### После запуска
- User Service: http://localhost:8081  
- Chat Service: http://localhost:8082  
- WS ws://localhost:8082/ws
- Kafka: localhost:9092 / 9093  
- Zookeeper: localhost:2181

## API эндпоинты

### User Service
- `POST /register` — регистрация  
- `POST /login` — логин  
- `POST /login/anon` — анонимный вход  
- `POST /refresh` — обновить токен  
- `POST /logout` — выйти  

### Chat Service
- `GET /messages?limit=10&offset=0` — история сообщений  
- `DELETE /message` — удалить сообщение  
- `GET /ws?token=`Ваш токен`` — подключение к WebSocket (авторизация обязательна,анонимный пользователь тоже получает токен)  

### Notification Service
- Консьюмер Kafka, пишет логи в `/logs`
